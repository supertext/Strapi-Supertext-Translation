# Supertext Translation for Strapi

Translate Strapi 5 entries into other locales with **Supertext AI**, straight from the Content Manager.

Open an entry, tick the languages in the **Supertext translation** panel, click **Translate with Supertext** — the plugin translates every localized text field (including rich text, components and dynamic zones) in one request per language and saves the result as a draft for review.

![Demo: in Strapi's Content Manager an editor ticks German and French in the Supertext translation panel, clicks Translate with Supertext and opens the German draft of the article](docs/images/demo.gif)

- Works with Strapi's built-in internationalization (i18n) and its role permissions per locale
- Keeps rich-text formatting and links; copies numbers, dates and media; rebuilds URL slugs
- A Supertext language per locale, chosen in a combo box under *Settings → Supertext* (obvious defaults preselected), and formal/informal tone where Supertext offers it
- Optional *Translation review* per locale: reviewers correct translations on the website, and their corrections come back with the next translation
- Automatic API key check; optional version information for Supertext support (no content, no key)
- Re-translate an existing locale on demand, with a clear warning first
- Export for translation as XLIFF 1.2 (for translation tools) or HTML, and import the translated file with a summary of what was imported

## Export for translation and import (XLIFF and HTML)

Besides translating with Supertext AI, you can export an entry as a file, have it translated elsewhere and import the result.

- **Where:** the *Export for translation* and *Import translation* sections of the Supertext panel in the Content Manager.
- **Formats:** XLIFF 1.2 for translation tools such as Trados, memoQ or Phrase (formatting travels as protected tags; several target languages in one file), or HTML (one language per file) for translators or Supertext's web app, which keeps the file's head and `data-st-id` attributes, so the translated file imports as it is.
- **Import:** the file says what it was exported from and for which language. The translations are written with the same rules as a Supertext AI translation, and a summary shows what was imported and what was skipped: source changed since the export (import those anyway with *Also import texts whose source changed since the export*), not translated, formatting changed, not in the file.
- **Safe:** files over 10 MB, files from another system and translations that add markup the source doesn't have are refused; uploaded files aren't stored.

Details: [user guide](docs/USER_GUIDE.md#export-for-translation-and-import-a-translated-file).

Quick start (not on npm yet — see the installation guide for building the package):

```js
// config/plugins.js
module.exports = ({ env }) => ({
  supertext: { enabled: true, config: { apiKey: env('SUPERTEXT_API_KEY') } },
});
```
